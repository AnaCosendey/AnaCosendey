# 👩🏻‍💻 Ana Marina Cosendey

**`Engenheira de Software`**

Sou estudante de Sistemas de Informação na Universidade de São Paulo (USP) e atuo como Engenheira de Software Júnior no Itaú Unibanco, na Comunidade de Inteligência Artificial, com foco em soluções de Machine Learning e MLOps.

Atualmente, trabalho com a plataforma **Amazon SageMaker**, atuando na homologação e sustentação do produto para uso em todo o banco, incluindo pipelines, Lambdas de atualização, instalação, manutenção e suporte aos usuários. Também contribuo com o **Lotus**, SDK de MLOps desenvolvido sobre o SageMaker, na frente de modelagem e treinamento.

Tenho interesse em **Machine Learning Engineering**, buscando me desenvolver cada vez mais em MLOps, engenharia de dados e construção de soluções de Machine Learning.
